# Local Problem-Solving Hub

A community-driven platform for reporting, tracking and resolving local issues with transparency, participation and accountability.

## Overview

Local Problem-Solving Hub is a PHP-based web platform designed to help residents report, discuss and resolve community issues in a structured and transparent way. The system connects local people with area-based admins so that problems affecting a neighborhood can be reported, reviewed, prioritized and addressed efficiently.

Residents can submit issues specific to their area, vote on the urgency of those issues, share comments and suggestions and stay informed about progress. Area admins are assigned to specific localities and are responsible for monitoring reported concerns, updating their status and helping resolve them. The platform also allows admins to organize offline community meetings and track participation through RSVP responses.

The goal of this project is to create a digital bridge between citizens and local authorities, making it easier for communities to stay informed, participate actively and work together toward a cleaner, safer and more organized environment. By combining reporting, collaboration, voting and progress tracking, Local Problem-Solving Hub promotes stronger community engagement and faster issue resolution.

## Features

- User registration and login for local residents and admins
- Area-based admin system for community management
- Problem reporting by residents within their assigned area
- Area-restricted visibility so users only see issues from their own locality
- Voting system for problem prioritization
- Comments and suggestions on reported problems
- Problem status tracking from Pending to Resolved
- Monthly progress reports showing:
  - Number of problems resolved
  - Number of problems in progress
- Offline community meetings organized by admins
- RSVP system for meetings:
  - Going
  - Not Going
- Admin dashboard for managing area-specific issues and meeting participation

## How It Works

1. Local residents register and select their area.
2. A resident reports an issue affecting their locality.
3. Other residents in the same area can view the issue, vote on it and add comments.
4. Area admins review the reported issue and take action.
5. The issue status is updated as it moves from Pending to Resolved.
6. Monthly reports highlight the progress of local problem-solving efforts.
7. Admins arrange community meetings and track attendance through RSVP responses.

## Tech Stack

This project is built using:

- PHP
- MySQL
- CSS
- HTML

The system uses PHP for backend logic and user interaction, MySQL for structured data storage and CSS for the user interface and styling.

- Improve community participation in solving local issues
